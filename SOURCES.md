# Data sources

**Status: all cost/impact figures are placeholder planning-level ranges — none are cited yet.**
They were authored for prototyping and must be replaced with sourced figures before Reclaim is used to argue real numbers in public meetings. The app shows a persistent disclaimer until then.

## Verification checklist

| Element(s) | What to verify | Candidate sources |
| --- | --- | --- |
| Café table, big table, bench, bar counter | Installed streetery/parklet furnishing costs | NYC DOT Open Restaurants / Dining Out NYC design guide; SF Shared Spaces cost guidance |
| Planter, tree | Street tree + planter install cost | NYC Parks street tree cost data; municipal forestry budgets |
| Rain garden | Green-infrastructure cost per sq ft | EPA green infrastructure cost-benchmark literature |
| Turf patch | Sod/turf install cost | Landscaping cost indexes (RSMeans-style) |
| Bike rack, bike corral | Program install costs | SFMTA & PBOT bike corral program docs |
| Bus shelter | Shelter procurement + install | Transit agency procurement records (King County Metro, LA Metro) |
| Scooter dock | Vendor dock hardware pricing | Lime/Spin/Veo public program agreements |
| Studio home (ADU) | Small-ADU construction range | UC Berkeley Terner Center ADU cost surveys |
| Vendor kiosk | Prefab kiosk pricing | Vendor list prices; city market-stall programs |
| Trash bins (containerized) | On-street containerization cost | NYC DSNY containerization pilot reports |
| Little library | Kit pricing | Little Free Library official kits |
| Parcel locker | Locker hardware + install | Luxer One / Parcel Pending list pricing |
| Public art | Small placemaking grant ranges | Municipal placemaking grant programs |
| Corner bumpout (daylighting) | Quick-build vs. capital cost | NACTO Urban Street Design Guide; city quick-build program costs |

## Figures that are defensible today

- **Parking space footprint: 8 × 20 ft = 160 sq ft** — a common standard stall size (varies by jurisdiction; cite local code when presenting).
- **Square-footage math** — computed from element footprints on a 1-ft grid, not estimated.

When a figure is verified, update the `source` field on the element in `src/data/elements.ts` and note the citation here.
